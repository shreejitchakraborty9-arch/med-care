---

## 📌 Overview

**MedCare WB** is a dual-portal public health platform built to solve healthcare supply bottlenecks, bed shortages, and epidemic response delays across West Bengal. It connects 25 major state hospitals and rural Primary Health Centres (PHCs) spanning all **23 administrative districts** with automated AI-driven supply rebalancing and real-time citizen access.

---

## 🚀 Key Features

### 1. Administrative Command Dashboard (`dashboard.html`)
- **Real-Time Statewide Telemetry:** Live synchronization with Firebase Firestore (`onSnapshot`) tracking occupied vs. free beds, pharmaceutical buffers, and emergency declarations.
- **AI Agent Notification Sidebar:** Right-docked slide-over panel with unread badges, audio chime for `CRITICAL` alerts, and an interactive "DONE" resolution workflow stored in Firestore (`agent_alerts`).
- **Emergency Declaration Protocol:** Instant state-level health emergency activation with district-wide alert banners, pulsing map pins, and automated inter-district resource mobilization plans generated by Gemini AI.
- **Interactive Geospatial Map (`map.js`):** Visual mapping of West Bengal facilities via Google Maps API, color-coded by occupancy rates with custom SVG pins and popups.
- **Official NIC/HMIS Design Standard:** Clean governmental design language with real-time IST clock, district filters, search, and `@media print` executive reporting.

### 2. Multi-Agent AI System (`agents.js` & `gemini.js`)
Powered by Google's **Gemini AI** (`gemini-3.5-flash-lite`), three independent agents operate autonomously in the background:
- 💊 **Medicine Supply Agent (`MedicineAgent`):** Analyzes pharmaceutical stock across all facilities every 5 minutes. Detects stockouts (0 units), rapid depletion (<20 units), overstocking (>500 units), and formulates inter-facility transfers.
- 🛏️ **Hospital Bed Management Agent (`BedAgent`):** Monitors facility occupancy every 3 minutes. Flags critical saturation (>90%), overflow preparation (>80%), and re-routing to underutilized facilities (<40%).
- ⚠️ **Epidemic Early Warning Agent (`EpidemicAgent`):** Evaluates cross-hospital patterns every 10 minutes. Detects regional symptom clusters, dual-drug depletion (e.g., Paracetamol + ORS during gastro outbreaks), and computes a 0–100 district Pandemic Risk Index.

### 3. Citizen Availability Portal (`user-view.html`)
- **Mobile-First Public Directory:** Accessible, high-contrast interface designed for citizens and ambulance drivers.
- **"Find Nearest Hospital with Free Beds":** Uses HTML5 Geolocation (`navigator.geolocation`) and the **Haversine Distance Formula** to rank facilities with available beds by physical distance (in km) and visually highlight the closest option.
- **Real-Time Search & Map Toggle:** Instant filtering by hospital or district name, with toggleable interactive map view.

## 🛠️ Technology Stack

- **Frontend:** Semantic HTML5, CSS3 (NIC / HMIS Govt Portal standards), Vanilla JavaScript (ES Modules).
- **Database & Auth:** Firebase Firestore (Real-Time `onSnapshot`), Firebase Authentication.
- **AI / LLM:** Google Gemini API (`gemini-3.5-flash-lite`).
- **Maps & Geolocation:** Google Maps JavaScript API, HTML5 Geolocation API, Haversine algorithm.
- **Runtime & Deployment:** Node.js (Universal Seeder), Firebase Hosting (`firebase.json`).

## ⚙️ Installation & Local Setup

### 1. Clone Repository
```bash
git clone https://github.com/shreejitchakraborty9-arch/med-care.git
cd med-care
```

### 2. Configure Environment Keys
Create a `.env` file in the root directory and copy the contents from `.env.example`:
```ini
FIREBASE_API_KEY=your_firebase_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
MAPS_API_KEY=your_google_maps_api_key_here
GEMINI_MODEL=gemini-3.5-flash-lite
```

Create `env-config.js` for local browser execution:
```javascript
window.ENV = {
  FIREBASE_API_KEY: "your_firebase_api_key_here",
  GEMINI_API_KEY: "your_gemini_api_key_here",
  MAPS_API_KEY: "your_google_maps_api_key_here",
  GEMINI_MODEL: "gemini-3.5-flash-lite"
};
```
*(Note: `.env` and `env-config.js` are excluded from git via `.gitignore` to prevent secret leakage).*

### 3. Install Dependencies
```bash
npm install
```

### 4. Seed Firestore Database
Populate your Firestore `hospitals` collection with verified West Bengal facilities:
```bash
npm run seed
```

### 5. Start Local Server
```bash
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser:
- **Admin Portal:** Select "Admin Login" -> redirects to `dashboard.html`.
- **Citizen Portal:** Select "Citizen Login" -> redirects to `user-view.html`.

---

## 🔒 Security & Privacy

- **Zero Hardcoded Secrets:** All API keys and model parameters are externalized into `.env` and local `env-config.js`.
- **Hosting Protection:** `firebase.json` explicitly ignores `env-config.js`, `.env`, `seed.js`, and `node_modules` from public deployment.
- **Route Guarding:** Synchronous `<head>` security checks in both `dashboard.html` and `user-view.html` prevent unauthorized URL access.
